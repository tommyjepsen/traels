# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussion about the work. Harassment,
personal attacks and discriminatory language aren't tolerated.

Report unacceptable behaviour privately to the maintainer via
[GitHub private reporting](https://github.com/tommyjepsen/traels/security/advisories/new) or by
contacting [@tommyjepsen](https://github.com/tommyjepsen). Reports are handled confidentially.
