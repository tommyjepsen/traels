# Security policy

Traels fetches user-supplied URLs, runs yt-dlp, and loads models from the Hugging Face Hub, so
security reports are taken seriously.

Please **don't open a public issue** for vulnerabilities. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/tommyjepsen/traels/security/advisories/new).
You'll get a reply as soon as possible, and a fix and advisory are coordinated with you before
anything is disclosed.

Only the latest release is supported.
